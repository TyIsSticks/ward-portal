Restoring a backup

Restoring replaces everything, so it’s done from the server with the portal stopped (not from this page). A copy of what’s being replaced is saved first as a Before a restore backup.

docker compose stop portal
docker compose run --rm portal python -m app.cli restore-backup /data/backups/<file>.zip
docker compose start portal

To restore a file you downloaded, copy it into data/backups first.
